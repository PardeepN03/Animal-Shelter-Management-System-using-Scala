
# Animal Shelter Management System

## Project Overview
Animal Shelter Management System is a Scala-based application that helps manage animals, adoption records, and shelter staff.

## Features
1. Add new animals.
2. View all available animals.
3. Search animals using Animal ID.
4. Adopt animals.
5. View adoption records.
6. Add shelter staff.
7. View staff details.
8. Handle invalid adoption requests using custom exceptions.

## Technologies Used
- Programming Language: Scala
- Build Tool: SBT
- IDE: Visual Studio Code
- Java Development Kit: JDK

## How to Run the Project

1. Install JDK and SBT.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
sbt run
```
